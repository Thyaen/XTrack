# Hardware

## Description
This guide provides an overview of the hardware setup for the XTRACK autonomous vehicle. It includes instructions for assembling components such as the Raspberry Pi, sensors, motors and power supply. It serves as a reference for building, understanding, and maintaining the system.

## Components
### Raspberry PI
The central onboard computer responsible for running the ROS 2 software stack, processing sensor data, and executing control commands. It provides interfaces to the sensors, motors, and communication systems.  
<img src="docs/img/raspberry_pi.jpg" alt="Raspberry Pi" width="600"/><br>
### LiDAR
A 2D Light Detection and Ranging sensor that continuously scans the surroundings to detect obstacles and map the environment. It serves as the primary sensor for SLAM and collision avoidance.  
<img src="docs/img/lidar.jpg" alt="LiDAR" width="600"/><br>
### IMU
An Inertial Measurement Unit (IMU) that provides orientation and acceleration data. It enhances localization accuracy by complementing LiDAR data in the SLAM process and helps maintain stable motion control. (WIP)  
<img src="docs/img/imu.jpg" alt="IMU" width="600"/><br>
### PI Kamera
A lightweight camera module used to provide a visual feed of the robot's environment. The video stream can be accessed remotely via the web interface and may also be used for visual monitoring.  
<img src="docs/img/camera.jpg" alt="camera" width="600"/><br>
### Motors & ESC
The vehicle is driven by two DC motors, each controlled via an Electronic Speed Controller (ESC). The ESCs receive PWM signals generated by the Raspberry Pi to adjust motor speed and direction.  
<img src="docs/img/motor.jpg" alt="motor" width="600"/><br>
*Motor*
<img src="docs/img/esc.jpg" alt="ESC" width="600"/><br>
*Electric Speed Control (ESC)*
### Batteries
Rechargeable battery packs that supply power to the entire system, including the Raspberry Pi, sensors, and motors.  
<img src="docs/img/batteries.jpg" alt="batteries" width="600"/><br>
### Client
A separate device (typically a laptop or PC) that connects to the robot over the network. It is used to launch the control interface, visualize the SLAM map in RViz2, and monitor the live video feed.  
### Controller
A USB or Bluetooth gaming controller is used to manually steer the vehicle. It allows real-time teleoperation of the robot, providing direct control over speed and direction. This is especially useful during testing or when switching to manual mode in critical situations.  
<img src="docs/img/controller.jpg" alt="controller" width="600"/><br>
